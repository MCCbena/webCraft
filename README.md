# WebCraft

Web言語(TypeScript)で書いたMinecraft風ゲーム。Java Edition 1.13 仕様のレッドストーン回路、16×16チャンク(256×256ブロック)の地形生成、サバイバル/クリエイティブモードを搭載。

- **エンジン**: TypeScript + Vite + Three.js
- **レッドストーン**: ダスト伝播(減衰・ラインルール)・トーチ・リピータ(1-4tick)・コンペア(比較/減算)・ピストン(12ブロック推進・スティッキー)・オブザーバ・ランプ・レバー/ボタン/圧力プレート — 20 TPS同期ティック
- **地形**: シード決定論的(バイオーム: 平野/森/砂漠/山岳/海洋、樹木、鉱石、海)
- **テスト**: 164件のユニットテスト(Vitest)

## 操作

| キー | 動作 |
|---|---|
| マウス | 視点移動(クリックでロック) |
| WASD / Space | 移動 / ジャンプ(水中でも) |
| 左クリック(長押し) | 破壊(硬度による) |
| 右クリック | 設置 / レバー・ボタン操作 / 食べ |
| 1-9 / ホイール | ホットバー選択 |
| E / Esc | インベントリ開閉(Shift+クリックでホットバー移動) |
| F | サバイバル ⇄ クリエイティブ |
| Space×2 | (クリエイティブ) 飛行ON/OFF |
| F3 | デバッグ画面 |

## 開発

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm test         # ユニットテスト
npm run build    # プロダクションビルド
npm run verify   # CPUラスタライザで地形/レッドストーンPNG生成
```
