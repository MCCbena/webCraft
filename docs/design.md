# WebCraft — Web言語製Minecraftクローン 設計書

## 1. 要件(ユーザー指定)
- Web言語(TypeScript)でMinecraft風ゲームを作成
- Java Edition 1.13 仕様のレッドストーン回路(ダスト伝播・リピータ・コンペア・ピストン・オブザーバ等)
- 16チャンク地形生成 → **16×16チャンクの世界(256×256ブロック、高さ256)** をシード付き決定論的に生成
- サバイバルモード(HP・空腹・ダメージ・インベントリ・ブロック採掘/設置)
- クリエイティブモード(飛行・即破壊・無限アイテム)
- gitでバージョン管理
- その他は実装者判断で補完(UI・テクスチャ・サウンド等)

## 2. 技術スタック
- TypeScript + Vite + Three.js(レンダリング)
- Vitest(ユニットテスト、ブラウザ不要の純ロジックテスト)
- 外部アセット不使用:テクスチャは Canvas で 16×16 タイルのテクスチャアトラスを生成
- Node 24 / npm / git 使用

## 4. ブロック・アイテム定義
- 地形系: air, stone, grass, dirt, sand, gravel, log(oak), leaves, planks, cobblestone, glass, water, bedrock, clay, snow
- 鉱石系: coal_ore, iron_ore, redstone_ore
- レッドストーン系(1.13 **完全版**): redstone_dust, redstone_torch, redstone_block, redstone_lamp(+lit), repeater(向き+1~4tick), comparator(向き+compare/subtract), piston(向き), sticky_piston(向き), observer(向き), lever(on/off), stone_button, wood_button, stone_pressure_plate, wood_pressure_plate, **tripwire_hook + tripwire(弦ブロック)**, **hopper(向き+5スロット)**, **dispenser(向き+9スロット)**, **dropper(向き+9スロット)**, **daylight_detector(通常/反転)**, **note_block(音階0-24)**, **tnt(通常/着火中)**, **rail, powered_rail**
- 機材系: torch, **door(oak: 上下2ブロック・閉=ソリッド・給電で開閉)**
- プロパティ: solid, opaque, hardness(破壊時間), drop(ドロップアイテム), meta(向き0-3 / オンオフ / 強度 / 遅延 / 音階 / 開閉), pushable
- アイテム: 各ブロック + wheat, bread(空腹+5), apple(空腹+4), stone_pickaxe(等), **tripwire(弦アイテム: ハック接続用)**

## 5. ワールド・チャンク
- チャンク: 16(X)×256(Y)×16(Z)。`Uint8Array` 2枚(id / meta)。index = (y*16+z)*16+x
- 世界: 16×16チャンク(256×256ブロック、座標 -128..127、中心スポーン (0, 最高地点, 0))
- 生成: 決定論的シード(デフォルト 1337、URL ?seed= で変更)。Perlin/Simplex ノイズ(自作実装可)
- メッシュ: 表示距離 ±3 チャンク(7×7=49チャンク)のみメッシュ化、プレイヤー移動で再計算。バックグラウンド生成はチャンク単位の lazy
- 水: 半透明マテリアル、フェーズ分離メッシュ
- 保存: localStorage に世界シード・プレイヤー状態(簡易、任意)

## 6. 地形生成(16×16チャンク、1.13風)
- 高さ: 多倍オクターブノイズ。ベース y≈64、山脈帯(山:最高≈200)
- バイオーム: 平野(草)、森(樹木密度高)、砂漠(砂+枯れ草)、山岳(岩+雪)、海洋(水深1-8、砂底)
- 樹木: オーク(幹4-6、葉のブロック)、森で高密度
- 鉱石: 石の内部に鉄・石炭(浅い)/レドストーン(深い、y<16)をクラスタ配置
- ベドロック: y=0 層(y<8 に混在)
- 決定論: 同じシードで同じ世界(テスト対象)

## 7. プレイヤー
- 操作: 鼠标+キーボード(ポインタロック)、WASD移動、Spaceジャンプ、左クリック破壊(長押し)、右クリック設置、1-9/ホイール選択、Eインベントリ、Fモード切替、F3デバッグ
- 物理: AABB(幅0.6×身長1.8)、重力、摩擦、水内減速(簡易)、落下ダメージ(生存)
- サバイバル: HP20(心10)、空腹20、空腹0でHP減少、落下ダメージ(5ブロック以上)、voidダメージ、溺死、ブロック硬度に応じた破壊時間、ドロップ取得(手元)
- クリエイティブ: 飛行(Space上昇/Shift下降、ダブルSpaceでON/OFF)、即破壊、非ダメージ、無限アイテム
- 目線到達 6ブロック

## 8. レッドストーン(Java 1.13 完全版) — 最重要モジュール
**原則: 実装漏れは許されない。1.13 の全レッドストーン要素(電源・伝播・応答ブロック・コンテナ)を実装する。**

### 8.1 電力モデル
- 弱電力: 水平4隣接ブロックに与える。強電力: 上(下方のブロックが上に与える)に与える
- ダストは上の圧力プレートを**起動しない**(プレートはエンティティ検出のみのセンサー、1.13準拠)。代わりにダストは上のドアを開く(弱電力)
- 電源(出力15):
  - レッドストーントーチ(無電源時): 弱=水平4+下、強=上
  - レバーON: 弱=水平4+下(取付)、強=上
  - ボタン(押下中): 同上
  - 圧力プレート(踏圧時): 同上
  - オブザーバ(検出後2tick): 弱=前面方向、強=前面ブロック上
  - レドストーンブロック: 弱=水平4、強=上
  - ディスペンサ/ドロッパー/**ハッパー**(**中身がある時**): 弱=後方のブロックのみ(1.13準拠)
  - **トライブワイルフック(弦がトリガー中)**: 弱=水平4、強=上
  - **パワーレール(給電時)**: 弱=水平4(ダストへ14)、強=上
  - **昼光センサー(通常/反転)**: 弱=水平4+下、強=上(出力0-15、時間依存 §8.6)
- **消灯した(電力を受けた)トーチ**と**点灯したランプ**は電源にならない(1.13準拠。点灯中のトーチは出力15の電源)

### 8.2 ダスト伝播(1.13準拠の固定点法)
- 各ダストの強度 0-15 を、全ダストについて反復計算(固定点まで、最大30回):
  - 水平隣ダスト N: `s(N)-1`
  - 水平隣電源ブロック N: `power(N)-1`
  - 下ブロックの強電力: `strongPower(below)`(例: レドストーンブロック上のダスト=15)
  - **ラインルール**: 水平直線上2つ先のダスト C に対して、C が既に強度15の場合のみフル強度(15)を減衰なしで与える。それ以外の場合は通常の隣接伝播(sN-1)のみ。これにより単調減衰(14,13,…)が保たれ、自己維持ラインは起きない(1.13準拠)。
- 変化があれば隣接ブロックの電力状態・ランプ点灯・コンポネント入力を再計算し、伝播再実行(変更なしで収束するまで)
- **活動範囲: 世界全体**(16×16チャンクは常時アクティブ。コンポーネント登録 Map で疎管理し毎ティック走査)

### 8.3 論理コンポーネント(20TPS, tick=50ms)
- **リピータ**: 背後から入力、1~4tick遅延で出力=入力強度(維持)。入力継続中も出力は継続(1.13のロック)。右クリックで遅延1→4切替
- **コンペア**: compare= max(back, side1, side2)、subtract= max(back-side, 0)、出力=入力強度維持。右クリックでモード切替
- **ピストン**: 給電→2tick後に伸展(最長12ブロック、ピストン連鎖可、bedrock等は不可)、非給電→2tick後に縮小。stickyは縮小時に前面ブロックを引きずる。**伸張先がプレイヤーAABBと交差したら2HPダメージ(1.13)**
- **オブザーバ**: 前面ブロックのid/meta変化を検出→2tick間出力15(弱+強)
- **トーチ**: 電力(水平4+下、下=ダスト含む)を受けたら消灯
- **ランプ**: 6隣接の弱電力または下の強電力で点灯(meta切替)
- **ボタン**: 石=10tick/木=20tickで自動OFF
- **圧力プレート**: 上1マスにエンティティが存在なら15

### 8.4 応答ブロック
- **ドア(oak)**: 上下2ブロックで1つのドア。閉=ソリッド(1×2 AABB)、開=非ソリッド。**下の半分が電力(水平4の弱電力 or 下ブロックの強電力)を受ければ開く**、電力喪失で閉じる。右クリックでも開閉トグル。描画: 閉=全面板、開=端に小さな板2枚
- **TNT**: 給電で着火(80tick=4秒の導火)。着火中は白色表示+音。**爆発: 半径4、bedrock以外を破壊(ドロップなし)、プレイヤーは距離減衰ダメージ(中心12→端0)、爆発音+視覚フラッシュ**
- **音符ブロック**: 給電(立ち上がり)で音。音階はmeta 0-24(右クリックでサイクル、デフォルト12)、周波数 `80 * 2^(n/12)` Hz。上のブロックで音色変化(木=ギター、毛=ベース、石=スネア、鉄=ハイハット、他=ベース)

### 8.5 コンテナ(中身システム)
- **ハッパー**: 5スロット。毎ティック(8tick間隔で)上隣接コンテナから引き、下隣接コンテナへ押し(1回2アイテム)。中身あり=給電源(後方のみ)
- **ドロッパー**: 9スロット。給電中、8tickごとに1アイテム前面へ射出(前面が空=ブロックアイテムなら設置、コンテナなら投入、そうでなければ滞留)。中身あり=給電源(後方のみ)
- **ディスペンサ**: 9スロット。給電中、8tickごとに1アイテムを前面に「使用」(ブロック=設置、TNT=着火、ドア=開閉トグル)。中身あり=給電源(後方のみ)
- **コンテナGUI**: 右クリックで開く(9/5スロット+プレイヤーインベントリ表示、クリックで移動)。E/Escで閉じる

### 8.6 昼光センサーと昼夜サイクル
- 世界時間: 24000tick=1日(20分)、開始 time=1000(1.13デフォルト)
- 昼光センサー出力: 太陽高度 sin ベース `clamp(round(15 * max(0, sin(π * t/12000))), 0, 15)`(0≤t≤12000=昼、夜=0)。反転モード=15-出力
- 空の色/フォグは時間に応じて変色(昼=青、夜=暗色)

### 8.7 トライブワイル
- **フック**: ソリッドブロック上に設置(右クリック)。弦アイテムを手に右クリックで、視線方向40ブロック以内の別フック(同一Y・直線・中間がair/弦のみ)と接続
- **弦(tripwireブロック)**: 接続経路のairセルに弦ブロックを配置(非ソリッド・細い線描画)
- **トリガー**: プレイヤーAABBが弦と交差→両端フックが15出力(弦の存在間継続)。ブロック設置・フック破壊で切断
- 設置不能: 中間にソリッドブロックがあると接続不可

### 8.8 レール
- **rail**: 非ソリッド、小さな描画(地面に設置)
- **powered_rail**: 給電(下ブロックの電力 or 隣接ダスト/電源の弱電力)時に電源化(§8.1)
- (マインカートは車両要素のため本スコープ外。回路としての電力挙動は完全)

### 8.9 テスト必須シナリオ(既存+追加)
- 既存: 減衰境界(14→0)、ラインルール15、リピータ(遅延/維持/ロック/連続給電)、コンペア、ピストン(12/13/bedrock/sticky)、オブザーバ2tick、トーチ/ランプ
- **追加**: ダストが上の圧力プレートを給電、昼光センサー(昼=高/夜=0/反転)、トライブワイル(接続→プレイヤー交差→両フック15→離れて消灯→ブロック設置で切断)、ドア(給電で開/非給電で閉、閉=ソリッド衝突)、TNT(給電→80tick→爆発で半径4のブロック消失+プレイヤーダメージ、bedrock無傷)、ハッパー(上コンテナ→ハッパー→下コンテナ伝送)、ドロッパー(給電で前面にブロック射出)、ディスペンサ(前面にブロック設置)、コンテナ中身あり=後方給電、ピストンによるプレイヤー2HPダメージ、昼夜サイクル(time=18000で昼光センサー0、time=6000で15)
